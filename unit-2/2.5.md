# Compound Boolean Expressions

- The not operator (!) inverts the boolean value.

```
boolean a = true;
boolean b = !a; // equal to false
```

- The and operator (&&) evaluates whether all conditions are true. 
- The or operator (||) evaluates whether at least one condition is true. 
- Logic operators also have an order of presedence:
- !(not) then &&(and) then ||(or)

true && !false || false || !true && false evaluates to true
false || false || false || true evaluates to true

# if Statements

- An if Statement is a type of selection statement.
- It's a one-way selection statement, executing a segment of code only when a boolean expression is true.
- An if-else Statement is a two-way selection statement, executing a segment of code when a boolean expression is true and one when it's false.
- Selection statements give you the power to change the sequential execution of statements.

```
if (BooleanExpression) {
  // Code Segment
} else {
  // Code Segment
}
```

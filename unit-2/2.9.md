# Implementing Selection and Iteration Algorithms

- Standard algorithms combine loops (iteration) with if statements (selection) to solve common problems.
- Common ones: divisibility, extracting digits, counting frequency, finding min/max, and computing sums/averages.
- Most of these use an accumulator: a variable declared before the loop that gets updated inside it.

**Divisibility**

- Use % to check if a number divides evenly. If the remainder is 0, it's divisible.

```
// Print every number from 1 to 100 that is divisible by 7
for (int i = 1; i <= 100; i++) {
    if (i % 7 == 0) {
        System.out.println(i);
    }
}
```

**Extracting Digits**

- num % 10 gives the last digit.
- num / 10 removes the last digit (integer division truncates).
- Repeat until the number becomes 0.

```
int num = 4096;
while (num > 0) {
    int digit = num % 10;
    System.out.println(digit);
    num /= 10;
}
// Prints: 6, 9, 0, 4 (digits come out in reverse order)
```

- Counting digits or summing digits works the same way, just with a counter or sum variable.

```
int num = 4096;
int digitSum = 0;
while (num > 0) {
    digitSum += num % 10;
    num /= 10;
}
// digitSum = 19
```

**Frequency (Counting)**

- Start a counter at 0 before the loop and increase it each time a condition is true.

```
// Count how many numbers from 1 to 50 are odd
int count = 0;
for (int i = 1; i <= 50; i++) {
    if (i % 2 != 0) {
        count++;
    }
}
// count = 25
```

**Minimum and Maximum**

- Keep track of the smallest/largest value seen so far, and replace it when a smaller/larger one is found.
- Initialize min/max to the first value, not to 0. If all values are negative, a max of 0 would be wrong.
- Integer.MAX_VALUE (for min) and Integer.MIN_VALUE (for max) also work as starting values.

```
Scanner scan = new Scanner(System.in);
int max = scan.nextInt(); // first value
for (int i = 1; i < 5; i++) {
    int value = scan.nextInt();
    if (value > max) {
        max = value;
    }
}
System.out.println("Max: " + max);
```

- For minimum, flip the comparison to value < min.

**Sum and Average**

- Start sum at 0 and add each value to it inside the loop.
- Cast to double before dividing, or integer division will truncate the average.

```
int sum = 0;
for (int i = 1; i <= 4; i++) {
    sum += i;
}
double average = (double) sum / 4;
// sum = 10, average = 2.5
// sum / 4 without the cast would be 2
```

- Be careful to not divide by 0 if there are no values (count == 0).

# for Loops

- A for loop is an iterative structure that repeats instructions a fixed number of times. 
- A for loop is more efficient, especially if you know how many times you want the code to be repeated.
- The biggest difference between the for loop and the while loop is that the update element of the loop is built into the structure of the loop in the for loop. 
- Syntax:

```
for (initialization; boolean expression; update) {
    // will execute if the boolean is true and continue until the boolean is false. 
}
```

- The initialization component creates a variable used to control the flow of the loop, called the "Loop Control Variable".
- The boolean expression must eventually become false so the for loop will stop executing.
- The update component changes the value of the loop control variable and is executed after the body of the loop is executed.
- Example:

```
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}

// Prints: 0, 1, 2
```

- for loops are better for programs with a predetermined number of iterations, and while loops are better for programs with an undetermined number of iterations.
- Example for while loop: Getting the user to enter a password until it's the correct one.
- Example for for loop: A user wants to know which numbers are divisible by 3 between 0 and 100.

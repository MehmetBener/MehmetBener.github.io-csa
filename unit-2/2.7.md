# while Loops

- A while Loop will continue to iterate or repeat a set of statements until a condition is met.
- When a loop iterates one too few or one too many times, it's referred to as an off-by-one error. Here the boolean condition is very important (decision like whether to put a < or <= etc. )

```
while (BooleanExpression) {
  // Code will execute if BooleanExpression = true
  // and continue until BooleanExpression = false
}
```

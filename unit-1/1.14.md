# 1.14 Calling Instance Methods

- Instance methods are not static methods. They don't belong to a class.
- Instance methods are used for objects. Not the whole class. So they are used on instances of the class.
- Class method: Class.method();
- Instance method: Object.method();
- So you use the object name.
- If you call a method on an object whose value is null, it will result in an error.
- Non void methods return a value.
- A getter is a method that takes no arguments and has a non-void return type. It retrieves an attribute.

# 1.3 Expressions and Output

- System.out.println(value);
- Put a backslash before quotes to print quotes.
- Backslash n makes a new line.
- An arithmetic expression that uses at least one double value will always evaluate to a double value.
- When doing division with two integers, it's truncated (the decimal is thrown out). 
- 9 / 10 = 0 in Java because of truncating.
- 3 % 5 = 3. Small number modulus a larger number evaluates to the smaller number.

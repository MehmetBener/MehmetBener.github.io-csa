# 1.15 String Manipulation

- A string is a series of characters.
- The String class is part of the java.lang package like the Math class.
- Strings can be concatenated using the plus (+) sign.
- A string object is immutable (When it's created, it can never be changed). The memory in the memory location of the previous value stays. A new address is found for the new value.
- Strings can be reused from memory from the String Pool.
- The new keyword when creating a String forces Java to not use the String Pool.
- Java automatically converts a primitive value to a String when concatenated.
- A String's length is the number of chars.
- Each character has an index in a String.

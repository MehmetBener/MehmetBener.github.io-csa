# 1.13 Creating and Initializing Objects: Constructors

- Each class has constructors which are used to initialize the attributes in a newly created object.
- Constructors have the same name as the class.
- An argument is a value that is passed into a constructor.
- Arguments are used to initialize the attributes of an object.
- Constructors are the parameters of objects.
- Overloading the constructor is when there are more than one constructors.
- Objects are reference type variables. Reference is a memory address.
- "null" is a value that can be assigned to reference type variables (Objects and Strings).
- A class can have constructors inside the class with all the different possible combinations of arguments passed in.
- The parameters inside the constructors must be defined previously.
- We can't instantiate a Math object because it doesn't have a public constructor. But we don't need the object because we can call the static methods from the class itself. 
- See in code below:

```
public class Date {

    private int year;
    private int month;
    private int day;

    public Date()
        { /** Implementation not shown */ }

    public Date(int year, int month, int day)
        { /** Implementation not shown */ }

     public void print()
        { /** Implementation not shown */ }

}
```

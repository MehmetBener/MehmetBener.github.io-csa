# 1.10 Calling Class Methods

- Every class has attributes and methods.
- The main method runs automatically without being needed to be called.
- Class methods are methods that belong to a class itself and can be called without creating an instance of the class.
- Instance methods are methods that can only be called using the object that you create from the class.
- All class methods need to have the static keyword. Without the static keyword, it would be an instance method.
- ClassName.classmethod(arguments); helps you call a class method from another class without creating an instance of the class.
- Class methods make code more organized while reducing redundancy and the chance of error, and are perfect for helper classes.
